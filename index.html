ARCHIVOS EN EL BADGE
Contenido guardado

          
Listado por RCSP 0x0C (igual que la app oficial). Borrado por clúster (0x1F) con respaldo por nombre (0x23). Las vistas previas se leen del badge (0x24): solo el primer cuadro de cada archivo, y quedan guardadas en este navegador.

          

          
Conectá el badge y tocá Actualizar para ver sus archivos.

          
Si el listado no muestra el archivo pero conocés su nombre (aparece en la pantalla del badge), borralo por nombre.

          
Borra todo el contenido del almacenamiento de medios del badge (SD1). Es el mismo comando "formatear" del SDK de Jieli; pide doble confirmación y no se puede deshacer.

Cómo funciona


  1. Creá en Crear, Pixel Lab o Arcade. Todo se previsualiza en la pantalla redonda.
  2. Preparar para el badge genera un AVI MJPEG (JPEG baseline con tablas estándar, lo que el chip Jieli decodifica bien).
  3. Conectá con Chrome, Edge u Opera por HTTPS. Poné el badge en modo Bluetooth (botón BT) y elegí E01 / E87 / L8.
  4. Enviá: el badge pide los datos por ventanas, confirma el nombre y cierra la transferencia.
  5. Mi badge lista los archivos guardados, permite borrarlos, ajustar brillo, idioma y hora, y guarda un registro para diagnóstico.


Sin Web Bluetooth (Safari, Firefox, iPhone) podés crear y descargar el AVI; para enviarlo usá Chrome en Android, Windows, macOS o ChromeOS.
